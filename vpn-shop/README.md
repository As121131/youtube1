# VPN-магазин в Telegram: инструкция по запуску

Готовый комплект, чтобы продавать VPN-подписки через Telegram-бота.
Собран из двух открытых проектов:

| Компонент | Что делает | Лицензия |
|---|---|---|
| [Remnawave](https://github.com/remnawave/panel) | Панель управления VPN: пользователи, трафик, сроки, серверы (на базе Xray: VLESS Reality и др.) | AGPL-3.0 |
| [Remnashop](https://github.com/snoups/remnashop) | Telegram-бот продаж: тарифы, оплата, пробный период, рефералка, промокоды, рассылки | MIT |

Бот сам выдаёт ключи после оплаты, продлевает подписки, напоминает об окончании и
отключает неоплативших. Вам остаётся только привлекать клиентов.

---

## ⚠️ Прочитайте до запуска

- **Законы.** В России с 1 марта 2024 года запрещена реклама способов обхода
  блокировок, а Роскомнадзор блокирует VPN-протоколы. Продажа VPN — серая зона:
  платёжные системы (ЮKassa и т.п.) могут отказать в приёме платежей. Если вы
  в другой стране, проверьте местные правила. Это не юридическая консультация.
- **Оплата.** Самые надёжные варианты для такого бизнеса — **Telegram Stars** и
  **крипта (CryptoPay / Heleket / Cryptomus)**. Все они уже встроены в бота.
- **Налоги.** Доход нужно декларировать (например, как самозанятый/ИП).
- **Ответственность.** Вы отвечаете за то, что делают клиенты через ваш сервер.
  Выбирайте хостинг, который разрешает VPN/прокси (это указано в его правилах).

## Сколько стоит и сколько можно заработать

**Расходы на старт (~$10–15 в месяц):**

| Что | Где | Цена |
|---|---|---|
| Сервер 1 — панель + бот (2 ядра, 2–4 ГБ RAM, Ubuntu) | любой VPS (Hetzner, Aeza, Timeweb Cloud и т.п.) | ~$5–8/мес |
| Сервер 2 — VPN-нода (1 ядро, 1 ГБ RAM) в Нидерландах/Германии/Финляндии | любой VPS с безлимитным или большим трафиком | ~$4–6/мес |
| Домен | Namecheap, Reg.ru, Porkbun | ~$2–10/год |

**Экономика:** одна нода за ~$5 спокойно тянет 100–300 пользователей.
Чтобы выйти на **$500/мес** при цене ~$3 за месяц нужно **~170 платящих**
подписчиков. Каждые +150–200 клиентов — ещё одна нода за $5.

Пример тарифов (настраиваются в боте):

| Тариф | Цена | В Telegram Stars* |
|---|---|---|
| Пробный | 3 дня бесплатно | — |
| 1 месяц | 199 ₽ / $2.5 | ~200 ⭐ |
| 3 месяца | 499 ₽ / $6 | ~500 ⭐ |
| 12 месяцев | 1690 ₽ / $20 | ~1700 ⭐ |

\* Telegram выплачивает разработчику ~$0.013 за звезду (через TON на Fragment),
а покупатель платит за звёзды больше из-за комиссий App Store/Google Play.
Цены в звёздах ставьте с запасом.

## Что нужно заранее

1. **Два VPS** с Ubuntu 22.04/24.04 (см. таблицу выше).
2. **Домен** и две DNS-записи типа **A**, обе на IP **сервера 1**:
   - `panel.вашдомен.com` — панель;
   - `bot.вашдомен.com` — бот (для вебхуков Telegram и платёжек).
3. **Бот в Telegram**: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните токен.
4. **Ваш Telegram ID**: напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт число.
5. **Аккаунт поддержки** — username, куда клиенты будут писать вопросы (можно ваш).

## Шаг 1. Панель (сервер 1)

Скопируйте папку `vpn-shop` на сервер 1 (или просто два скрипта) и выполните:

```bash
sudo bash install-panel.sh
```

Скрипт спросит два домена, установит Docker, панель Remnawave и Caddy
(HTTPS-сертификаты получатся автоматически).

**Сразу после этого** откройте `https://panel.вашдомен.com` и зарегистрируйтесь —
**первый** зарегистрированный аккаунт становится супер-админом. Не откладывайте,
иначе это может сделать кто-то другой.

---

## Шаг 2. VPN-нода (сервер 2)

1. В панели: **Nodes → Management → «+»**. Укажите страну, имя, IP сервера 2,
   порт ноды (например `2222`), выберите Config Profile.
2. Нажмите **«Copy docker-compose.yml»**.
3. На **сервере 2**:

   ```bash
   curl -fsSL https://get.docker.com | sh
   mkdir -p /opt/remnanode && cd /opt/remnanode
   nano docker-compose.yml   # вставьте скопированное, сохраните (Ctrl+O, Enter, Ctrl+X)
   docker compose up -d
   ```

4. Закройте порт ноды для всех, кроме панели (замените `IP_СЕРВЕРА_1`):

   ```bash
   ufw allow 22/tcp
   ufw allow 443/tcp
   ufw allow from IP_СЕРВЕРА_1 to any port 2222 proto tcp
   ufw enable
   ```

5. В панели вернитесь к ноде, нажмите **Next → Create**. Через несколько секунд
   нода станет зелёной.

**Настройка протокола.** По умолчанию в профиле только Shadowsocks. Для работы
в условиях блокировок добавьте инбаунд **VLESS + Reality** на порту 443 в
**Config Profiles**, затем создайте для него **Host** и добавьте в **Internal Squad**.
Подробно с картинками: официальный быстрый старт —
<https://docs.rw/docs/learn/quick-start> (на русском).
Для автоматической установки ноды с Reality есть скрипт
[remnawave-scripts](https://github.com/DigneZzZ/remnawave-scripts).

Проверка: создайте в панели тестового пользователя, импортируйте его ссылку
подписки в приложение (Happ, v2rayTun, Hiddify, Streisand) и убедитесь, что
интернет работает.

---

## Шаг 3. Бот (сервер 1)

1. В панели: **Settings → API Tokens → создать токен** — скопируйте его.
2. На **сервере 1**:

   ```bash
   sudo bash install-bot.sh
   ```

   Скрипт спросит домен бота, токен от BotFather, ваш Telegram ID, username
   поддержки и API-токен панели. Остальные секреты сгенерирует сам и свяжет бота
   с панелью (вебхуки уже настроены в шаге 1).

3. Откройте своего бота в Telegram → `/start`. Так как вы владелец, в меню будет
   **админ-панель**.

---

## Шаг 4. Настройка продаж (в боте, без кода)

В админ-панели бота:

1. **Тарифы** — создайте пробный (3 дня) и платные тарифы, задайте цены,
   срок, лимит трафика и устройств.
2. **Платёжные системы** — включите **Telegram Stars** (работает сразу, без
   договоров) и, при желании, **CryptoPay** (токен берётся в [@CryptoBot](https://t.me/CryptoBot) →
   Crypto Pay → Create App). Также доступны ЮMoney, ЮKassa, Robokassa, FreeKassa,
   Heleket, Cryptomus и др. — для них нужен аккаунт в самой платёжке.
   Сделайте тестовую оплату.
3. **Реферальная программа** — например, +7 дней за каждого приглашённого,
   который оплатил. Это главный бесплатный канал роста.
4. **Уведомления** — включите напоминания об окончании подписки (возвращают
   клиентов).
5. **Рекламные ссылки** — создавайте отдельную ссылку под каждое место размещения,
   чтобы видеть, откуда приходят покупатели.

## Где брать клиентов

- **Рефералка** — уже встроена. Давайте бонус обоим: и пригласившему, и новичку.
- **Пробный период** — 3 дня бесплатно сильно повышает конверсию.
- **Сарафанное радио** — первых 20–50 клиентов обычно дают знакомые, коллеги,
  студенческие чаты. Хорошее качество → советуют дальше.
- **Тематические чаты и каналы** — учитывайте запрет на рекламу VPN в РФ: прямую
  рекламу размещать нельзя, рискуете блокировкой.
- **Узкие ниши** — геймеры (низкий пинг), фрилансеры (доступ к зарубежным
  сервисам), путешественники, русскоязычные за границей (доступ к российским
  сервисам из-за рубежа — тоже спрос).

## Обслуживание

```bash
# логи
cd /opt/remnawave && docker compose logs -f
cd /opt/remnashop && docker compose logs -f remnashop

# обновление
cd /opt/remnawave && docker compose pull && docker compose up -d
cd /opt/remnashop && docker compose pull && docker compose up -d
```

- **Бэкапы** — обязательно. В боте есть автобэкапы (настраиваются в админке, файлы в `/opt/remnashop/backups`);
  для панели удобен `remnawave backup` из
  [remnawave-scripts](https://github.com/DigneZzZ/remnawave-scripts).
- **Масштабирование** — при росте просто добавляйте ноды (шаг 2) в разных
  странах; бот выдаёт клиентам подписку сразу на все.
- **Файлы `.env` никогда не публикуйте** — там токены и пароли.
